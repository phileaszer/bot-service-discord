Sécurité & confiance

Tu dois savoir exactement ce que Sentinel fait.

Sentinel aide à gérer les services, les sanctions, les annonces et les tickets. Il respecte les permissions Discord et ne garde que les informations nécessaires au fonctionnement du serveur.

Accès

Le staff autorisé garde la main.

Les commandes de gestion passent par les rôles choisis dans Sentinel. Le propriétaire du serveur garde un accès de secours en cas d’erreur de configuration.

  • /config-permissions
  • Rôles dédiés au staff
  • Démarrage sécurisé

Modération

Discord garde toujours le dernier mot.

Si Sentinel n’a pas la permission nécessaire ou si son rôle est trop bas, l’action est refusée.

  • Permission Discord vérifiée
  • Hiérarchie des rôles respectée
  • Logs de modération

Données

Le stockage reste limité.

Sentinel garde seulement ce qui sert aux services, aux logs, aux réglages serveur, aux sanctions, aux tickets et au dashboard.

  • Données séparées par serveur
  • Pas de vente de données
  • Politique de confidentialité disponible

Transparence

Ce qu’un admin doit savoir avant d’inviter Sentinel.

Les permissions servent à faire les actions demandées par ton serveur. Sentinel ne contourne pas Discord : si son rôle est trop bas ou si une permission manque, l’action est refusée.

01

Ce qui est stocké

Identifiants Discord du serveur, des utilisateurs, des rôles et des salons configurés, temps de service, sessions, sanctions, tickets, annonces, sessions dashboard et journal des actions.

02

Ce qui n’est pas stocké

Pas de mot de passe, pas de token utilisateur, pas d’informations de paiement, pas de vente de données et pas d’enregistrement de messages privés.

03

Pourquoi ces permissions

Le bot doit envoyer ses messages, gérer le rôle de service, créer les salons de tickets, joindre les comptes rendus, appliquer les sanctions demandées et écrire dans les logs.

04

Comment garder la main

Place le rôle Sentinel assez haut, limite les rôles autorisés, utilise /diagnostic et garde les logs visibles par le staff.

05

Supprimer des données

Les heures d’un membre peuvent être remises à zéro avec /reset-heures. Pour une demande plus large sur les données d’un serveur, passe par le serveur support.

06

Informations publiques

Le site montre seulement les informations utiles aux visiteurs : état général, serveur support, fonctions disponibles et règles de confidentialité.

FAQ

Les questions que les admins posent le plus.

Des réponses courtes pour comprendre Sentinel avant de l’ajouter à un serveur.

Pourquoi Sentinel demande ces permissions ?

Pour envoyer ses messages, gérer le rôle de service, écrire dans le salon de logs et appliquer les sanctions demandées par le staff.

Que faire si le bot n’apparaît pas ?

Retire l’intégration, puis réinvite Sentinel avec le bouton officiel. Dans Discord, il doit apparaître comme bot, pas seulement comme commandes.

Comment configurer le rôle de service ?

Utilise /config-role, choisis le rôle donné aux membres en service, puis place le rôle Sentinel au-dessus de ce rôle.

Comment remettre les heures d’une personne à zéro ?

Utilise /reset-heures avec le membre ou son ID Discord. Le reset de tout le serveur est prévu pour le Premium.

Est-ce que Sentinel lit les messages privés ?

Non. Sentinel ne lit pas les messages privés et ne stocke pas les conversations privées des utilisateurs.

Comment demander la suppression de données ?

Pour les heures d’un membre, utilise /reset-heures. Pour une demande concernant les données d’un serveur, contacte le support Sentinel avec l’ID du serveur concerné.
